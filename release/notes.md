# v3.13.1

## 问题修复

- 修复 OpenAI OAuth 请求混用客户端与代理安装 ID 的问题：HTTP 和 WebSocket 不再透传独立的 `x-codex-installation-id` 请求头，正文及 turn metadata 统一使用 CPR 为当前账号保存的安装 ID，同账号和切换账号时均保持一致
- 修复 API Key 上游的完整 Codex 模型目录被简化的问题，保留推理档位、默认值、能力、提示词及未知字段；按客户端版本请求并缓存目录，普通模型列表未提供的推理能力保持未知
- 修复额度刷新等并发更新引起的账号快照冲突，选号时有限重读并重新校验账号资格，避免请求在出站前误报基础设施错误；冲突重试不占用并发名额或请求间隔
- 修复系统时钟回拨导致请求终态无法保存、随后被误记为超时的问题，保留真实结果与实际耗时；账号更新时间也不再倒退
- 修复额度重置成功后弹窗关闭和额度刷新不及时的问题：确认成功后立即关闭弹窗，后台刷新对应账号，保留列表分页、选择和展开状态；额度回读失败时明确提示重置已成功
- 修复默认账号并发上限无法设为 `0`（不限制）的问题，账号独立上限仍优先生效，继续统计在途请求并遵守请求间隔；Dashboard 和分组正确显示无限容量

## 体验优化

- 账号连接测试的事件轨迹和原始诊断完整展开，统一使用弹窗外层滚动，便于查看较长错误信息

## 升级说明

- 从 v3.13.0 升级会自动执行新增迁移 `0017_unlimited_default_account_concurrency.sql`，仅放宽默认账号并发上限约束；已有正数设置保持不变，旧迁移未修改，无需调整部署配置
- 对接 Dashboard 或分组管理 API 的客户端需处理 `totalSlots: null`（无限容量）；Dashboard 的 `availableSlots` 在无限容量时也为 `null`，`usedSlots` 继续表示实际在途数
