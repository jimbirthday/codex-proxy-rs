# v3.13.0

## 新增功能

- CCSwitch 导入会同时配置当前客户端密钥的日／周额度查询，展示总额、已用和剩余金额并默认每 30 分钟刷新；新增只读的 `GET /v1/usage` 接口，查询不会调用上游、占用推理并发或产生使用记录
- 密钥使用统计页新增「关于」入口，客户端密钥持有者可查看当前版本号和提交号
- 管理端使用统计和 Dashboard 最近请求会在账号邮箱下显示账号的当前备注；同邮箱账号仍按内部账号 ID 区分，已删除账号的历史记录不会误关联备注

## 问题修复

- 在线更新改为后台任务，长时间下载不再受 HTTP 请求生命周期影响；页面刷新或响应丢失后可恢复查看运行状态，更新完成待重启时会阻止重复执行。没有可用更新时继续显示当前版本的发布说明和链接
- OpenAI 账号容量冷却只统计明确的过载拒绝，普通 `5xx`、未识别上游错误和 `invalid_prompt` 不再误触发冻结；流式 `invalid_prompt` 按请求错误处理
- 账号额度预测保留当前周期已记录的用量，只估算剩余容量；额度重置后重新建立采样，避免把前一周期用量混入新周期。重新启用已停用账号时保留已有额度、凭据错误和冷却状态
- 修复第三方客户端或跨客户端继续会话时，OpenAI OAuth 上游拒绝 reasoning 历史的问题：HTTP 与 WebSocket 会移除不受支持的 `status`，并在已有加密历史时去除冗余明文内容，其他输入保持不变

## 体验优化

- 长上下文计费详情改为主题一致的黄色提示图标，并补充悬停说明和无障碍标签
- 密钥额度文案统一使用「周」，CCSwitch 中不限额密钥明确显示「不限额」

## 升级说明

- 从 v3.12.1 升级不新增数据库迁移，也无需调整配置
